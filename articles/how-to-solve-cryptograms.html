How to Solve Cryptograms: Rules, Tips and Strategies for Beginners

By UtilityPuzzles · August 2026

A cryptogram is a coded sentence: every letter has been swapped for a different letter of the alphabet, and your job is to figure out the code. It looks like gibberish at first, but it's one of the most satisfying puzzles to crack — because English is full of patterns, and once you spot a few of them the whole sentence unfolds. Here are the rules and the strategies that will have you decoding in minutes.

The rules in one minute

The hidden message is a real sentence, and every code letter stands for exactly one plaintext letter — the substitution never changes within a puzzle. If the code letter Q stands for E in one word, it stands for E everywhere. Each plaintext letter is coded by exactly one code letter, so the code is a perfect one-to-one swap, and — in a genuine code like the ones our cryptogram generator makes — no letter is ever coded as itself.

How to read the code

Every time you solve one code letter, fill it in for every occurrence of that letter across the whole puzzle — that's the golden rule of cryptograms. On our cryptogram maker, typing a letter under any code letter fills every occurrence automatically, and the letter strip at the bottom of the puzzle tracks your whole alphabet: the code letters you've solved across the top, and the plaintext letters you've assigned below. Keep the strip tidy as you go, and you'll see at a glance which letters are still unsolved.

1. Start with one-letter words

English has only two one-letter words: A and I. If the code contains a single-letter word, it must be one of those two — try one, and if the sentence starts to feel wrong, switch to the other. It's a tiny clue, but it often unlocks the letters that appear most often.

2. Attack the short words next

Two- and three-letter words are the backbone of English. The most common are the, and, of, to, in, is, it, you, that, was, for. If you see a three-letter word with the same code letter at the start and end — like X Y X — it's almost certainly that or did. A three-letter word ending in the same letter as the one-letter word nearby is likely it or is. Each guess confirms a letter that appears elsewhere in the puzzle.

3. Look for repeated letter patterns

Double letters are the cryptogram solver's best friend. In code, a doubled letter means the plaintext has a doubled letter too — and English doubles are dominated by LL, EE, OO, SS, TT, FF and MM. Words like all, will, see, too, off, letter, happy all carry doubles. When you spot a pair of identical code letters side by side, you've usually found one of those seven pairs, which hands you two letters at once.

4. Lean on letter frequency

In any normal English sentence, some letters appear far more often than others. The most frequent are E, T, A, O, I, N, S, H, R — with E the clear winner. Count how often each code letter appears; the ones that turn up most are probably E, T or A. It's a statistical guess, but combined with a short word it becomes almost certain.

5. Watch for apostrophes

If the coded sentence shows an apostrophe, the word around it is almost certainly a contraction. Common ones are it's, don't, can't, won't, that's, I'm, you're. The letter right after the apostrophe is usually T (as in don't, can't, won't) or S (it's, that's). A contraction cracks three or four letters in one shot.

6. Know the common endings and beginnings

Whole chunks of English words repeat constantly. The most common endings are -ing, -tion, -ed, -ly, -er, -est, and the most common beginnings are th-, wh-, sh-, ch-, str-, pre-. If the last three letters of a longer code word match a three-letter pattern you've already solved elsewhere, the ending is likely -ing — and that single guess adds three letters and often reveals a whole word.

7. Use the "no letter codes itself" rule

Because no letter is ever coded as itself, a code letter can never stand for the same letter of the alphabet. So if you've deduced that the code letter M is probably M — stop, it can't be. This rule quietly rules out your most tempting guesses and keeps you from going down a wrong path. (It also means a one-letter word in the code is never an A coded as A — it's a genuine swap.)

8. Work back and forth, not top to bottom

Cryptograms solve in jumps, not in order. Solve a short word at the start, leap to a doubled letter in the middle, take a contraction near the end — each new letter confirms letters everywhere else, and the puzzle tightens like a knot. When you get stuck, count letter frequencies again and re-check the letter strip for letters you've solved but forgotten to apply.
