How to use the calcudoku maker

Pick a difficulty and a fresh puzzle appears instantly — every puzzle is different, and each one has exactly one solution.

  • Reading the grid: the thick lines mark the cages. Each cage shows its target number and operator — "12+" means the cage's numbers add to 12; "6×" means they multiply to 6; a lone number is a one-cell cage.
  • Solving: every row and every column must contain 1 to N exactly once, and each cage must reach its target. Digits can repeat inside a cage as long as the rows and columns allow. There is always exactly one way to fill the grid.
  • Solve on screen: click any blank and type a digit, or use the arrow keys to move between blanks. Check highlights anything wrong.
  • Printing: "Print / PDF" prints the blank puzzle — up to 2 per sheet. "Print Answers" prints the completed grid.

The rules of calcudoku

  1. Fill every blank cell with a number from 1 to N, where N is the grid size.
  2. Every row must contain each number 1 to N exactly once.
  3. Every column must contain each number 1 to N exactly once.
  4. Each cage's numbers must reach its target: + sums them, × multiplies them, − takes the difference of a two-cell cage, and ÷ takes the exact quotient of a two-cell cage.
  5. Digits may repeat inside a cage — only rows and columns forbid repeats.
  6. There is exactly one solution, reachable by logic.

Frequently asked questions

What is a calcudoku puzzle?

Calcudoku is the arithmetic logic puzzle made famous by KenKen. Fill an N×N grid so every row and every column contains the numbers 1 through N exactly once. The grid is divided into cages; the numbers in each cage must produce the cage's target number with its operator. Digits can repeat inside a cage as long as the rows and columns allow it.

What do the cage operators mean?

For a two-cell cage, − and ÷ mean the difference or the exact quotient of the two numbers (largest divided by smallest, always exact here). For any cage, + means the sum of its numbers and × means their product. A cage with no operator is a one-cell cage: the number is simply given.
