How to use the code breaker maker

Choose a theme, difficulty and clue option, and a fresh code sheet appears instantly — every sheet is different, and no two sheets on a page repeat the same words.

  • How it works: every word is written with the alphabet shifted by the same number of letters (a Caesar cipher). Decode one word and you've nearly cracked the whole sheet.
  • Strategy: with clues on, guess a word from its hint and work out the shift. With clues off, look for short coded words and common patterns to get started.
  • Check: type your answers under each code and click Check — wrong answers are highlighted until you fix them.
  • Printing: “Print / PDF” prints the puzzle with blank answer lines — up to 2 sheets per page. “Print Answers” prints the completed sheet.

The rules of code breaking

  1. Every coded word is a real word from the theme, written with the alphabet shifted by one fixed number of letters.
  2. The same shift is used for every word on the sheet — decode one word and the rest follow.
  3. Each word decodes to exactly one answer; every letter position keeps its length.
  4. Type or write each decoded word in full, then check your answers.

Frequently asked questions

How do you solve a code breaker puzzle?

Every coded word was made by shifting the alphabet by a fixed number of letters (a Caesar cipher). Try the same shift on every word, or use the clues to guess a word and work the shift out from there. Type your answer under each code and click Check.

Is the code breaker maker free?

Yes. Every generator on this site is completely free and unlimited. There is no account, no sign-up and no watermark, and you can generate as many puzzles as you like.

What does the clues option do?

Turning clues on adds a one-line hint under every coded word, turning the puzzle into a vocabulary exercise — great for classrooms. Turn them off for a pure decoding challenge.

How do I print a code breaker puzzle?

Click “Print / PDF” to print the puzzle with blank answer lines, or “Print Answers” for the completed sheet. In the print dialog choose “Save as PDF” to download a file.
