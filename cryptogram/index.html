How to use the cryptogram maker

Choose a theme and difficulty, and a fresh cryptogram appears instantly — every sheet is different, and no two sheets on a page repeat the same sentence.

  • How it works: the sentence is hidden with a letter-substitution cipher. Each code letter always stands for the same plaintext letter, and no letter stands for itself.
  • Solve on screen: type a letter under any code letter and it fills every occurrence automatically. The letter strip at the bottom tracks your whole alphabet.
  • Strategy: start with one-letter words (usually A or I), then short words, and look for repeated letter patterns like double letters.
  • Printing: “Print / PDF” prints the puzzle with blank answer lines — up to 2 per page. “Print Answers” prints the decoded sentence.

The rules of cryptograms

  1. The hidden message is a real sentence from the chosen theme.
  2. Every code letter stands for exactly one plaintext letter — the substitution never changes within a puzzle.
  3. No letter is ever coded as itself, so the substitution is always a genuine code.
  4. Letters revealed at the start (on easier levels) are already filled in for you.

Frequently asked questions

How do you solve a cryptogram?

Every letter in the coded sentence stands for a different letter of the alphabet. Look for short words, common letter patterns and repeated letters to guess letters, then fill every occurrence of that code letter at once. Use the letter strip at the bottom to track what you've solved.

Is the cryptogram maker free?

Yes. Every generator on this site is completely free and unlimited. There is no account, no sign-up and no watermark, and you can generate as many puzzles as you like.

What do the difficulty levels change?

Easy cryptograms use shorter sentences and reveal five letters up front, Medium reveals three, and Hard uses longer sentences with just one letter revealed. Every level uses a full letter-substitution cipher with no letter mapped to itself.

How do I print a cryptogram?

Click “Print / PDF” to print the puzzle with blank answer lines, or “Print Answers” for the completed sheet. In the print dialog choose “Save as PDF” to download a file.
