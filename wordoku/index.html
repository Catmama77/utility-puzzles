Wordoku Generator

Wordoku is sudoku with letters — fill every row, column and box so each contains every letter exactly once. Pick a theme and the letters come from that theme's words, making it a fun twist for solvers who find numbers dull. Choose 4 × 4, 6 × 6 or 9 × 9 grids at three difficulty levels, solve on screen, and print or download up to 8 puzzles per sheet with an answers option.

How to use the wordoku maker

Choose a theme, grid size and difficulty, and a fresh wordoku appears instantly — every puzzle is different, and no two puzzles on a page are ever the same.

  • Letters: each puzzle uses the first letters of the theme's words, so an Animals wordoku might use A, C, D, E, G, L, M, O, T. The letters in play are shown above every grid.
  • Difficulties: Easy and Medium give more starting letters; Hard leaves fewer clues. Start with 4 × 4 or 6 × 6 if you're new to the rules.
  • Solve on screen: click a cell and type a letter, or use the arrow keys to hop between empty cells. Check highlights anything wrong; the status line tells you when every entry is correct.
  • Printing: “Print / PDF” gives blank grids — up to 8 on one 8½ × 11 sheet. “Print Answers” prints the same batch filled in.

The rules of wordoku

  1. Every row must contain each of the puzzle's letters exactly once.
  2. Every column must contain each of the puzzle's letters exactly once.
  3. Every thick-bordered box must contain each of the puzzle's letters exactly once.
  4. Some letters are already placed as clues — use them to work out where the rest belong.
  5. There is exactly one solution, and it can be found by logic alone — no guessing needed.

Frequently asked questions

What is wordoku?

Wordoku is a sudoku variant played with letters instead of numbers. Fill every row, column and box so each contains every letter exactly once — the letters are usually the letters of a theme word, like the animals category here.

Is the wordoku generator free?

Yes. Every generator on this site is completely free and unlimited. There is no account, no sign-up and no watermark, and you can generate as many puzzles as you like.

How do I print wordoku puzzles?

Click “Print / PDF” to print the blank puzzle, or “Print Answers” for the completed grid. In the print dialog choose “Save as PDF” to download a file. You can also print up to 8 puzzles on one 8½ × 11 sheet.

Can children solve wordoku?

Yes. The 4×4 and 6×6 grids are ideal for beginners and young solvers — there are fewer letters to track, so the logic is easier to follow while still teaching the same row, column and box rules as sudoku.
