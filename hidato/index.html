How to use the hidato maker

Pick a difficulty and a fresh puzzle appears instantly — every puzzle is different, and each one has exactly one solution.

  • Reading the grid: the numbers 1 through N (N is the number of cells) must fill the grid in order, and each number must sit next to the previous one.
  • Solving: the start (1) and end (N) are always shown. Fill the blanks with the numbers in between, each one touching the previous number in any of the eight surrounding cells. There is always exactly one way to fill the grid.
  • Solve on screen: click any blank and type a number, or use the arrow keys to move between blanks. Check highlights anything wrong.
  • Printing: "Print / PDF" prints the blank puzzle — up to 2 per sheet. "Print Answers" prints the completed grid.

The rules of hidato

  1. Fill every blank cell with a number from 1 to N, where N is the total number of cells.
  2. Every number from 1 to N is used exactly once.
  3. Each number must sit in a cell next to the previous number — along a side or diagonally (all eight surrounding cells count).
  4. The start (1) and the end (N) are always given as clues.
  5. There is exactly one solution, reachable by logic.

Frequently asked questions

What is a hidato puzzle?

Hidato is a number-path puzzle invented by Gyora Benedek. Fill the grid with the consecutive numbers 1 through N so that each number sits in a cell next to the previous number — including diagonally — and every cell is used exactly once. Some numbers are given as clues, and the start (1) and end (N) are always shown.

Can numbers touch diagonally in hidato?

Yes. Consecutive numbers must sit in cells that touch at a corner or along a side — all eight surrounding cells count as "next to". So the number 15 can sit above, below, left, right, or in any of the four diagonal corners around the number 14.
